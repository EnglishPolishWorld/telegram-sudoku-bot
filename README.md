# Telegram Rich Sudoku

Sudoku-бот, работающий непосредственно внутри Rich Message Telegram. Игрок выбирает размер `4×4`, `6×6` или `9×9`, нажимает клетку и затем число. Отдельный сайт или Mini App не нужен.

## Моя роль

Проект создан в основном с помощью AI coding tools. Я задавал механику и требования к интерфейсу, разбивал функции на отдельные шаги, запускал версии, проверял игровые сценарии, воспроизводил ошибки и направлял следующие исправления.

Я **не представляю код как полностью написанный вручную мной**. Репозиторий показывает мой подход к AI-assisted prototyping, ручному тестированию, работе с состоянием игры и последовательной отладке.

## Возможности

- три размера с корректными блоками: `2×2`, `2×3` и `3×3`;
- классический и Killer Sudoku с суммами связанных областей;
- лёгкая, средняя и сложная головоломки;
- пять сердец, подсказки, отмена хода и таймер;
- ежедневная общая головоломка, статистика и рейтинг;
- общая игра в группе по команде `/group`;
- inline-запуск через `@username_бота` в любом чате;
- генерация головоломок с единственным решением;
- проверка повторов в строке, столбце и блоке;
- SQLite для сохранения активных партий;
- Docker/Compose для запуска;
- unit tests без обращения к Telegram.

## Быстрый запуск

```bash

python bot.py
```

```bash

```

## Команды

`/start` · `/sudoku` · `/new` · `/stats` · `/top` · `/rating` · `/group` · `/creator`

## Как устроен интерфейс

`sendRichMessage` отправляет выбор размера. Игровая доска строится как `InputRichBlockTable`, а каждая клетка содержит `RichTextButton`. Нажатия приходят как callback query. После изменения состояния бот обновляет то же сообщение.
