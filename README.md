# Telegram Rich Sudoku

Sudoku-бот, работающий прямо внутри Rich Message Telegram. Игрок выбирает размер `4×4`, `6×6` или `9×9`, нажимает клетку и затем число. Отдельный сайт или Mini App не нужен.

## Возможности

- размеры `4×4`, `6×6` и `9×9`;
- генерация головоломок с единственным решением;
- проверка строк, столбцов и блоков;
- обновление одного сообщения после каждого действия;
- работа в личных чатах и группах;
- сохранение игр в SQLite;
- только стандартная библиотека Python.

## Развёртывание на Railway

1. Создайте новый проект из этого GitHub-репозитория.
2. Добавьте переменную `BOT_TOKEN` со свежим токеном от `@BotFather`.
3. Добавьте volume, смонтированный в `/data`.
4. Добавьте переменную `DATABASE_PATH=/data/sudoku.sqlite3`.
5. Запустите Deploy. Railway автоматически использует `Dockerfile`.

Для первого запуска webhook, домен и HTTPS не нужны: бот работает через long polling.

## Локальный запуск

```bash
export BOT_TOKEN='ваш_токен'
python bot.py
```

Команды: `/start`, `/sudoku`, `/new`.

## Docker

Создайте рядом файл `.env`:

```dotenv
BOT_TOKEN=ваш_токен
```

Затем:

```bash
docker compose up -d --build
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

Токен в репозитории не хранится.
