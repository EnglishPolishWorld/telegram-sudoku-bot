# Telegram Rich Sudoku

Минимальный Sudoku-бот, работающий непосредственно внутри Rich Message Telegram. Игрок выбирает размер `4×4`, `6×6` или `9×9`, нажимает клетку и затем число. Отдельный сайт или Mini App не нужен.

## Возможности

- три размера с корректными блоками: `2×2`, `2×3` и `3×3`;
- классический и Killer Sudoku с суммами связанных областей;
- лёгкая, средняя и сложная головоломки;
- пять сердец, подсказки, отмена хода и таймер;
- ежедневная общая головоломка, статистика и рейтинг;
- общая игра в группе по команде `/group`;
- генерация головоломок с единственным решением;
- проверка повторов в строке, столбце и блоке;
- обновление одного сообщения после каждого действия;
- работа в личных чатах и группах;
- SQLite для сохранения активных партий;
- только стандартная библиотека Python, без сторонних пакетов.

## Быстрый запуск

1. Создайте бота у `@BotFather` и скопируйте токен. Не отправляйте токен посторонним.
2. Установите Python 3.11 или новее.
3. В каталоге проекта выполните:

```bash
export BOT_TOKEN='ваш_токен'
python bot.py
```

4. Откройте бота и отправьте `/start` или `/sudoku`.

Бот использует long polling, поэтому домен, HTTPS-сертификат и webhook для первого запуска не нужны.

## Запуск на Android без Termux

1. Установите [Pydroid 3](https://play.google.com/store/apps/details?id=ru.iiec.pydroid3).
2. Распакуйте ZIP-архив проекта в файловом менеджере.
3. В Pydroid 3 откройте файл `bot.py` из распакованной папки.
4. Нажмите кнопку ▶.
5. Когда появится `BOT_TOKEN:`, вставьте токен от `@BotFather` и нажмите Enter. В Pydroid введённый токен будет виден на экране — не делайте скриншот и не отправляйте его другим людям.

Токен не записывается в файлы. Бот работает, пока Pydroid продолжает выполнять программу. Для круглосуточной работы надёжнее использовать сервер.

## Docker

Создайте рядом файл `.env`:

```dotenv
BOT_TOKEN=ваш_токен
```

Затем запустите:

```bash
docker compose up -d --build
```

## Команды

- `/start` — открыть выбор размера;
- `/sudoku` — новая игра;
- `/new` — новая игра.
- `/stats` — статистика игрока;
- `/top` или `/rating` — рейтинг;
- `/group` — общая доска для участников группы.
- `/creator` — информация о создателе и кнопка запуска.

## Как устроен интерфейс

`sendRichMessage` отправляет выбор размера. Игровая доска строится как `InputRichBlockTable`, а каждая клетка содержит `RichTextButton`. Нажатия приходят как callback query. После изменения состояния бот вызывает `editMessageText` с новым `rich_message`.

Функция требует Telegram с поддержкой Bot API 10.3 Rich Message Buttons. Документация: <https://core.telegram.org/bots/api#rich-messages>.
